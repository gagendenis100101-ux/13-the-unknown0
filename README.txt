13 — THE UNKNOWN | Browser prototype 0.1

This is an early playable 3D browser prototype, not an Unreal Engine project or APK.
It uses Three.js from a CDN, so an internet connection is required.

CONTROLS (phone):
- Left virtual joystick: move.
- Drag the right side of the screen: look around.
- ACTION button: pick up / throw the ritual dice when close enough.
- SOUND button: toggle sound effects.

RUNNING:
The easiest phone-friendly option is to publish index.html using GitHub Pages:
1. Sign in to github.com in your phone browser.
2. Create a public repository named 13-the-unknown.
3. Upload index.html from this archive to the repository root.
4. Open repository Settings > Pages.
5. Under Build and deployment choose Deploy from a branch, select main and /(root), then Save.
6. Wait for the Pages URL and open it in Chrome on Android.

This prototype is a starting point. It does not yet include recorded demon voices, realistic hand animations, tarot, save data, or an APK build.
